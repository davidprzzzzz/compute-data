Questions

What is a GPU rental price index?

A GPU rental price index is a daily settled benchmark for cloud GPU rental prices, expressed in USD per GPU-hour. The Ornn Compute Price Index (OCPI) is built from executed trades across the neocloud market rather than listings, surveys, or provider rate cards.

Who publishes a GPU price index?

Ornn Data publishes the Ornn Compute Price Index (OCPI), a family of daily GPU rental price benchmarks: OCPI-H100, OCPI-H200, OCPI-B200, and OCPI-A100. The H100 and B200 indices (ORNNH100, ORNNB200) and the Anthropic and OpenAI token indices (ORNNTOKA, ORNNTOKO) are listed on Bloomberg, and the full calculation is published in the OCPI methodology.

What else Ornn prices: Every tracked lab (OTPI) · Memory spot prices · Forward curves and utilization · B300 Index (Enterprise) · The neocloud datacenter map

The GPU and token indices above are the free tier; Ornn tracks further hardware and labs behind paid tiers. With no API key, the free tier serves their latest daily values plus three months of history — see the API quickstart.

Where can I find a GPU price benchmark?

The Ornn Compute Price Index (OCPI) is a daily GPU price benchmark for H100 SXM, H200, B200, B300, A100 SXM4 and RTX PRO 6000 rental compute, settled in USD per GPU-hour from executed trades rather than listings or surveys. Each benchmark has its own price page with the latest settled value and a recent history table.

Where can I get GPU rental price data?

Ornn Data publishes daily settled GPU rental prices for H100 SXM, H200, B200, B300, A100 SXM4 and RTX PRO 6000. Three months of daily history are free as JSON through the API without a key; Premium adds full daily history (B300’s on Full), and hourly grain and exports require Full. OCPI-H100 (ORNNH100) and OCPI-B200 (ORNNB200) are listed on Bloomberg.

How do I track GPU rental prices over time?

Each GPU price page shows the daily settled index with a recent history table, so you can track the H100, H200, B200, and A100 rental benchmarks day by day. Three months of daily history are free as JSON through the API without a key, and the H100 and B200 indices are also on Bloomberg.

Are Ornn GPU prices provider list prices?

No. Ornn GPU prices are volume-weighted, winsorized averages of transacted rental deals. They are not a provider list price, bid, offer, or inventory quote for any one seller.

How can I compare H100, H200, B200, and A100 prices?

Compare current H100, H200, B200, and A100 settlements on the GPU cloud price comparison page. Every model uses the same transaction-based Ornn Compute Price Index methodology.

Is there a price index for AI tokens?

Yes. Ornn Data publishes the Ornn Token Price Index (OTPI): a daily USD-per-million-tokens benchmark for each major AI lab, volume-weighted across the lab's paid production models. The Anthropic (ORNNTOKA) and OpenAI (ORNNTOKO) indices are listed on Bloomberg, and three months of daily history are free.
